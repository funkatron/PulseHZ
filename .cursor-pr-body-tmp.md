## TL;DR
- **Autosave / restore:** `localStorage` project snapshot (`pulsehz:autosave-v1`, schema v1+v2) plus **IndexedDB** (`pulsehz-clip-cache-v1`) for user clips and audio; **same-origin demo paths** re-fetched on load (no blob for demos). Default loopback demo autoload is skipped when the last saved session had media, so restored empty slots are not overwritten.
- **Export WebM:** If playback was already running, export only called `resetTransport()` then `startPlayback()`’s no-op — capture never really started. Now **pause → reset → start** so recording always runs; status line explains **how long** (full audio file vs one bar without audio), with MediaRecorder error handling, timeslice chunks, stream track cleanup, and empty-capture messaging.
- **Visual downbeat:** Stronger, longer bar flash on the preview frame (inset + outer glow).
